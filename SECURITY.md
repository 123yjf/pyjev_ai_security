# Security boundary

This project annotates inert text after a response. It does not authorize actions, run tools, make network calls during inference, or send notifications. Model output is not proof of compromise or authorization. Document overlays, source attribution, data retention and incident response remain the integrator's responsibility.

Please do not include customer text, API tokens, secrets, live targets, or runnable attack payloads in issues. For a security-sensitive defect, use GitHub's private vulnerability reporting if enabled for this repository; otherwise open a minimal issue requesting a private contact without disclosing sensitive details. Use synthetic office examples for reproducible behavior.
